# SKHER Reinvention — Project Context

## What This Is
A single-page proposal website for the **新光醫院急診醫學科 科部再發展計畫** (Shin Kong Wu Ho Su Memorial Hospital — Emergency Medicine Department Redevelopment Plan).

Tagline: *Reinvent the Landscape of Emergency Medicine*

The source content lives in `introduction.pdf` (19 slides, Traditional Chinese).

## Key File
- `index.html` — standalone site, no build step, open directly in browser

## Content Structure
1. **Hero** — 新光醫院急診醫學科 · 科部再發展計畫
2. **Legacy** (#legacy) — 新光是現今台灣急診的起點; ~50% of Taiwan's top EDs built by Shin Kong alumni
3. **Vision** (#vision) — Emergency as patient gateway; tagline: 好的環境、好的品質、隨時可近
4. **Three Plans** (#plans) — Overview cards (dark navy background)
5. **急診加護病房** (#icu) — 12+2 beds, SKHEW early warning system, critical care buffer
6. **先進與革新急症技術中心** (#tech) — Ultrasound interventions, nerve block, PSA, 3–5 yr roadmap
7. **區域急診基地** (#community) — SKHTN transfer network, smart triage, EMS training
8. **Team** (#team) — 李瑋恩醫師 (featured) + 2 TBA slots
9. **Closing** — 急診醫學的未來，總是從新光開始
